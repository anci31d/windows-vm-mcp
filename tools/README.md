# Third-party tools

`x64dbg.zip` is an upstream binary snapshot included for convenience. It is not covered by this repository's MIT license. Check the x64dbg upstream terms before redistribution and replace the archive with a current snapshot when updating the project.

Sysinternals is intentionally absent because its redistribution terms are Microsoft-specific. `install-tools.ps1` downloads it from Microsoft's official URL only after explicit confirmation inside the guest.
